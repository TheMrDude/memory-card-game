# Memory Card Game 🃏

A fun, browser-based memory matching game built with HTML, CSS, and JavaScript.

## How to Play

1. Click on cards to reveal emojis
2. Match pairs of identical emojis
3. Try to complete the game with the least number of moves
4. Click "Reset Game" to start over

## Features

- 4x4 grid of emoji cards
- Move counter
- Responsive design
- Easy reset functionality

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

[Play Memory Card Game](https://yourusername.github.io/memory-card-game/)

## Local Setup

1. Clone the repository
2. Open `index.html` in your web browser
3. Start playing!
